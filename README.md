# 🏥 Hospital Emergency Room Analysis (Power BI Dashboard)

An end-to-end business intelligence project built using Power BI to analyze emergency room patient data, evaluate operational efficiency, and track key healthcare metrics.

---

## 🚀 Project Overview
This project provides insights into hospital emergency room operations. It helps hospital management track patient volumes, monitor average wait times, analyze department-wise patient distribution, and measure patient satisfaction scores.

---

## 🛠️ Tools & Technologies Used
- **Power BI Desktop:** For data visualization and dashboard creation.
- **Power Query Editor:** For data extraction, cleaning, and transformation (handling null values, formatting columns).
- **DAX (Data Analysis Expressions):** For creating calculated columns and measures (Total Patients, Average Wait Time, Distinct Counts, etc.).
- **Excel / CSV:** As the primary data source.

---

## 📊 Key KPIs & Metrics Included
1. **Total Patients:** Distinct count of patients visiting the emergency room.
2. **Average Wait Time:** Average time spent by patients waiting for treatment.
3. **Patient Satisfaction Score:** Average satisfaction ratings given by patients.
4. **Department Referrals:** Breakdown of patient distribution across various hospital departments.
5. **Gender & Age Demographics:** Analyzing patient trends across different age groups and genders.
